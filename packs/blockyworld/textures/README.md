# Texturas do conteúdo base

Coloque aqui os PNGs definitivos. O id de textura usado no JSON vira o caminho:

| id no JSON                         | arquivo                              |
|-----------------------------------|--------------------------------------|
| `blockyworld:blocks/stone`        | `textures/blocks/stone.png`          |
| `blockyworld:blocks/grass_top`    | `textures/blocks/grass_top.png`      |
| `blockyworld:items/<nome>`        | `textures/items/<nome>.png`          |

Enquanto o arquivo não existe, o jogo gera um placeholder com a cor
`placeholder_color` do bloco. Digite `/assets` no console para ver a lista do
que ainda falta e onde cada arquivo deve ficar. Detalhes: `docs/Assets.md`.
