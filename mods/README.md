# mods/

Mods empacotados com o projeto (carregados também no editor). Mods de
jogadores ficam em `user://mods/` (veja o botão "Open Mods Folder" no menu
Mods) ou, em builds exportados para desktop, em `mods/` ao lado do executável.

`example_mod` adiciona um bloco (`example:ruby_block`) e um item
(`example:ruby`) sem alterar nenhuma linha do código do jogo. Guia completo:
`docs/Modding.md`.
